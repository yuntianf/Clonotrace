Introduction

Understanding clonal structure and dynamics is a central problem in single-cell transcriptomics, particularly in immune and cancer biology. Modern single-cell technologies increasingly enable joint measurement of transcriptomes and clonal barcodes (e.g., TCR sequences or genetic lineage tracers), providing an opportunity to study how transcriptional states evolve at the clone level rather than at the level of individual cells.

Clonotrace is designed to analyze clonal behavior in single-cell data by integrating transcriptomic embeddings with clone information. Rather than treating clones as discrete labels, Clonotrace models each clone as a distribution of cells in a low-dimensional embedding space, enabling quantitative comparison of clonal transcriptional states.

This vignette provides a step-by-step tutorial demonstrating how to use Clonotrace to: - Estimate clone-level density in a cell embedding - Compute clone-to-clone distances using optimal transport (OT) - Cluster clones into transcriptional profiles - Perform downstream analyses such as profile-level pseudotime and gene association

Installation

Clonotrace can be installed from GitHub:

install.packages("devtools")
devtools::install_github("yuntianf/Clonotrace")

data

Clonotrace requires two main inputs:

A low-dimensional cell embedding, typically derived from PCA, or other dimensionality reduction methods applied to gene expression data.

A cell-by-clone identity matrix, which is a binary matrix to indicate if a given cell belongs to a given clone.

Throughout this vignette, we assume that the embedding has already been computed and that clone identity are available (e.g., from TCR sequence or lineage barcodes).

Clonewise transcriptomic distance

After we smooth the cell density for each expanded clone over the cell transcriptomic embedding, we can measure their cell distributional difference via optimal transportation distance.

We provide two methods for this, the first one calculates the exact optimal transportation distance, and the second one is a faster approximation, but less accurate. You can switch the modes by the exact parameter in the clone_disance function.

# not run
plan(multisession, workers = 8)
### exact OT distance
clone_dis = clone_disance(as.matrix(pca),cell_clone_prob,outpath = "./",exact = TRUE, cores = 8)
### nearest neighbor distance approximation
clone_dis = clone_disance(as.matrix(pca),cell_clone_prob,outpath = "./",exact = FALSE)

This step is time and memory consuming, which can take hours even with the approximation. We strongly recommend to put this step in a server or cluster and run it with multiple cores. (As a reference, the approximation method takes 40 minutes to run on the HPC paralleled with 4 cores using 8 Gb RAM).

Here for time efficiency, we can use the pre-computed clone-wise distance for downstream applications.

file_path <- system.file("extdata", "clone_graph_dis.tsv", package = "Clonotrace")
clone_dis = read.table(file_path,sep = "\t")

clone_dis = long2square(long = as.data.frame(clone_dis),row_names_from = "group1",
                        col_names_from = "group2",values_from = "dis",symmetric = T)
diag(clone_dis) = 0
rownames(clone_dis) = colnames(clone_dis) = colnames(cell_clone_prob)

clone weighted cell embedding (optional)

By integrating information from both the clone embedding and the cell embedding, we developed a new visualization method called clone-weighted cell embedding. In this representation, even if two cells are close in the transcriptomic (cell) embedding, they will be pulled apart in the clone-weighted embedding if their corresponding clones are distant in clone space. This embedding can better illustrate the clone level heterogeneity.

clone_k = 15

coembed_dis = cell_clone_coembed(cell_embedding,clone_embedding)

profile enrichment in each cluster

In the downstream analysis we will focus on the early bipotent profiles (profile) and detect early fate-associated genes. To achieve this goal we first do an enrichment test between profiles and clusters to show in which cluster profile 1 has significant high density. And then within the target cluster, we compare the gene expression between profile 1 and other profiles to identify early fate-associated genes.
