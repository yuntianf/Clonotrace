# embedding2knn

Compute k-Nearest Neighbor Graph from Embedding

## Usage

``` r
embedding2knn(embedding, k, mode = "connectivity", ...)
```

## Arguments

- embedding:

  A numeric matrix of embeddings (rows = observations).

- k:

  Integer. Number of nearest neighbors to use.

- mode:

  Character. Either \`"dist"\` for raw distances or \`"connectivity"\`
  for Gaussian kernel weights (default: \`"connectivity"\`).

- ...:

  Additional arguments passed to \`knn_flat()\`.

## Value

A sparse matrix representing the k-NN graph (class \`dgCMatrix\`).

## Details

Converts a data matrix (e.g., UMAP or PCA coordinates) into a k-nearest
neighbor graph. Returns a sparse matrix with either pairwise distances
or computed connectivities.
